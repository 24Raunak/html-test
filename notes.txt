The 'onload' attribute in html is an event handler that executes a script or a function when a specific object or image has finished loading.
Example:-
<img src="/static/img/code.jpg" onload="alert('image loaded')">
will display the 'image loaded' when the webpage has loaded.

difference between an id and class in html :-
an id is an attribute used to be a unique identifier within an html document. no two elements on a page will have the same id value.
a class attribute can be applied to multiple elements on a single page

the selector "p.example" in a .css file will select all the paragraphs which have been assigned the class "example"
or
the selector "p#hello" in a .css file will select the paragraph element which has been assigned the id "hello"
