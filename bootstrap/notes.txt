Bootstrap - used to build responsive websites

Two ways to get responsive design - 
1) Mobile first approach (better)
2) Desktop first approach

Responsive Break Points -
<576 px - extra small
576 px to 768 px - small
768 px to 992 px - medium
992 px to 1024px - large
>1024 px - extra large


Media query:-
1) Desktop First:-
    @media screen and (max-width:600px) {
    }
    
2) Mobile First:-
    @media screen and (min-width:600px) {
    }
