version control - track of how your file is changing over a period of time. who, when what

Git commands-
1) initialize git
    git init - initialize empty git repository

2) local changes -> staged changes
    git add filepath - for single files
    git add . - for multiple files

3) commit
    git commit -m 'message'

U - means untracked file

git config --global user.name 'username'
git config --global user.email 'email'


A (push) -> Remote Server -> B (pull)

git remote add origin https://github.com/24Raunak/CPP.git

Branching in git-
to create a new branch - git branch 'branchname'
to check existing branch - git branch
to checkout/switch to a branch - git checkout -b 'branchname'
